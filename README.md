## Stack

- Formulaire compatible GitHub Pages via FormSubmit (remplacer l’email avant mise en ligne)

## Structure
- index.html
- style.css
- script.js
- demos/
- images/

## Publication sur GitHub Pages
1. Créer un dépôt GitHub public ou privé.
2. Uploader tout le contenu du dossier à la racine du dépôt.
3. Aller dans Settings > Pages.
4. Choisir "Deploy from a branch".
5. Branche: main ou master.
6. Dossier: /root.
7. Enregistrer.
8. L’URL sera de la forme: https://username.github.io/nom-du-repo/

## À remplacer avant mise en ligne
- [REPLACE: your-email@example.com] dans le formulaire
- [REPLACE: https://instagram.com/yourhandle]
- [REPLACE: https://facebook.com/yourpage]
- [REPLACE: ...] dans les textes si nécessaire
- Ajouter les vraies images dans /images/
